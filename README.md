# Superstore Sales Data Analysis

## Project Overview

This project focuses on **understanding, cleaning, and analyzing Superstore sales data** using Python. The dataset is processed using Pandas and explored through statistical analysis and data visualization.

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

##  Project Tasks

* Load the Superstore sales dataset
* Inspect data using `head()`, `info()`, and `describe()`
* Convert Order Date and Ship Date into datetime format
* Clean categorical columns such as:

  * Category
  * Sub-Category
  * Segment
* Check missing values and duplicates
* Calculate numerical summary statistics
* Analyze Sales, Profit, Quantity, and Discount
* Analyze sales by Category and Region
* Create charts and visualizations
* Perform correlation analysis

##  Visualizations

The project includes:

* Sales by Category
* Profit by Category
* Sales by Region
* Yearly Sales Trend
* Correlation Heatmap
